
# Kasa

Avec plus de 500 annonces postées chaque jour, Kasa fait partie des leaders de la location d’appartements entre particuliers en France.




## Techologie

**Client:** React +Vite




## Installation

Installer Kasa:

Télécharger le zip ou cloner le projet via git.
Aller dans le dossier du projet extrait et lancer la commande:

```bash
  npm run dev
```
Le projet sera disponible à l'adresse http://localhost:5173/home
